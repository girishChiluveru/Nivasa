# 🏨 Nivasa - Hotel & Accommodation Booking Platform

A modern, full-featured hotel and accommodation booking platform built with the **MERN stack** (MongoDB, Express, Node.js, EJS). Nivasa provides users with a seamless way to search, browse, and book hotels with secure authentication and a responsive, mobile-friendly interface.

## ✨ Features

- **🔍 Hotel Search & Discovery**: Browse and filter hotels by location, price, amenities, and ratings
- **📱 Responsive Design**: Fully optimized for desktop, tablet, and mobile devices using Bootstrap and CSS
- **🔐 Secure Authentication**: Third-party login integration for enhanced security and convenience
- **💳 Easy Booking**: Intuitive booking flow with real-time availability checks
- **⭐ User Reviews & Ratings**: Read and leave reviews for accommodations
- **🛏️ Hotel Management**: Comprehensive details including amenities, photos, and pricing
- **📊 User Dashboard**: Track bookings, manage reservations, and view booking history
- **🚀 High Performance**: Optimized queries and caching for fast load times

## 🛠️ Tech Stack

### Frontend
- **HTML5** & **CSS3** with Bootstrap for responsive design
- **EJS** - Templating engine for dynamic page rendering
- **JavaScript** - Interactive UI components and form validation

### Backend
- **Node.js** - JavaScript runtime
- **Express.js** - Web application framework
- **MongoDB** - NoSQL database for storing hotel and booking data

### Tools & Services
- **Git & GitHub** - Version control
- **Environment Variables** (.env) - Secure configuration management

## 📋 Prerequisites

Before you begin, ensure you have the following installed:
- **Node.js** (v14 or higher)
- **npm** (comes with Node.js)
- **MongoDB** (local or MongoDB Atlas account)
- **Git** - For version control
